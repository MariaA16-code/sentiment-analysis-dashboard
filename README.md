# Sentiment Analysis Dashboard

## Overview
Built this to learn how NLP libraries work by applying sentiment detection 
to real text input.

## Tech Stack
- Python, Flask
- TextBlob
- HTML, CSS, JavaScript

## Features
- Real-time sentiment detection
- Simple and clean UI

## Run Locally
```bash
pip install -r requirements.txt
python app.py
```
